RAMSHI RENTALS

This is a beginner-friendly frontend project built with HTML, CSS and JavaScript.

Technology used:
- HTML5 = website content
- CSS3 = website design
- JavaScript = website actions

Project structure:
- index.html = home page
- rentals.html = main rental catalog
- bikes.html = bike rentals
- cars.html = car rentals
- cameras.html = camera rentals
- equipment.html = equipment rentals
- booking.html = booking page
- account.html = login, signup and rentals account
- about.html = business information
- contact.html = contact details and form
- css/style.css = all design and layout
- js/script.js = all front-end actions and validation
- images/ = rental and website images

Important separation:
- HTML contains the actual rental content and page text.
- CSS controls colors, layout, cards, buttons and responsive design.
- JavaScript adds actions like filters, menu toggles, booking logic and form validation.

Where students edit:
- Rental products: rentals.html
- Page content: HTML files
- Design: css/style.css
- Actions: js/script.js
- Images: images/

How to run:
1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click the index.html file.
4. Click Open with Live Server.

Notes:
- This is a frontend student project only.
- No backend, database or real payment system is used.
- All rental information is written directly in HTML.
